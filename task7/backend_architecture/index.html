    Infrastructure Architecture

    The monitoring platform observes the health of the Raspberry Pi edge cluster. It uses Prometheus for metrics collection, Node Exporter for machine-level metrics, Ansible for automated installation, and Grafana for dashboard visualization.

    Prometheus and Grafana run on the Raspberry Pi 5 master node. Node Exporter runs on the Raspberry Pi 3 worker nodes and exposes metrics on port 9100.

    Monitoring Architecture

    RP3 Worker Nodes
└── Node Exporter :9100
        ↓
RP5 Master Node
└── Prometheus :9090
        ↓
RP5 Master Node
└── Grafana :3000

    This architecture gives a central view of CPU usage, memory usage, disk usage, uptime, network activity, and node availability across the cluster.

    Component Location Purpose
    Node Exporter RP3 worker nodes Exposes host metrics such as CPU, memory, disk, network, and uptime
    Prometheus RP5 master node Scrapes and stores metrics from all Node Exporter targets
    Grafana RP5 master node Displays the collected metrics through dashboards
    Ansible RP5 master node Automates Node Exporter installation on the RP3 nodes

    Node Exporter Deployment

    Node Exporter was deployed to the RP3 worker nodes using Ansible. This avoids manually logging into each Raspberry Pi and installing the package one by one.

    Inventory used for the RP3 worker nodes:

    [rp3_nodes]
rpi3-01 ansible_host=192.168.50.101
rpi3-02 ansible_host=192.168.50.102
rpi3-03 ansible_host=192.168.50.103
rpi3-04 ansible_host=192.168.50.104
rpi3-05 ansible_host=192.168.50.105
rpi3-06 ansible_host=192.168.50.106
rpi3-07 ansible_host=192.168.50.107
rpi3-08 ansible_host=192.168.50.108

[rp3_nodes:vars]
ansible_user=pi
ansible_python_interpreter=/usr/bin/python3

    Playbook used to install and start Node Exporter:

    ---
- name: Install Prometheus Node Exporter on all RP3 nodes
  hosts: rp3_nodes
  become: yes

  tasks:
    - name: Update apt cache
      apt:
        update_cache: yes

    - name: Install Node Exporter
      apt:
        name: prometheus-node-exporter
        state: present

    - name: Enable and start Node Exporter
      systemd:
        name: prometheus-node-exporter
        enabled: yes
        state: started

    Verification from RP5:

    for ip in 101 102 103 104 105 106 107 108; do
  printf "192.168.50.%s: " "$ip"
  curl --connect-timeout 2 -s -o /dev/null \
    -w "%{http_code}\n" \
    "http://192.168.50.$ip:9100/metrics"
done

    A 200 response confirms that the exporter is running and reachable on that node.

    Prometheus Metrics

    Prometheus runs on the RP5 master node and scrapes all Node Exporter endpoints. It stores the metrics as time-series data and provides them to Grafana.

    Prometheus local access:

    http://localhost:9090

    Prometheus targets page:

    http://localhost:9090/classic/targets

    Prometheus Targets

    scrape_configs:
  - job_name: prometheus
    static_configs:
      - targets: ['localhost:9090']

  - job_name: node
    static_configs:
      - targets:
          - '192.168.50.101:9100'
          - '192.168.50.102:9100'
          - '192.168.50.103:9100'
          - '192.168.50.104:9100'
          - '192.168.50.105:9100'
          - '192.168.50.106:9100'
          - '192.168.50.107:9100'
          - '192.168.50.108:9100'

    Useful PromQL Queries

    Metric Query
    Node status up{job="node"}
    CPU usage 100 - (avg by(instance) (rate(node_cpu_seconds_total{job="node",mode="idle"}[5m])) * 100)
    Memory usage 100 - ((node_memory_MemAvailable_bytes{job="node"} / node_memory_MemTotal_bytes{job="node"}) * 100)
    Disk usage 100 - ((node_filesystem_avail_bytes{job="node",mountpoint="/"} / node_filesystem_size_bytes{job="node",mountpoint="/"}) * 100)
    Uptime (node_time_seconds{job="node"} - node_boot_time_seconds{job="node"}) / 3600
    System information node_uname_info{job="node"}

    In the up{job="node"} query, 1 means the node is reachable and 0 means the node is configured but unreachable.

    Grafana Dashboards

    Grafana is used as the monitoring user interface. It connects to Prometheus as a data source and visualizes the Raspberry Pi cluster metrics.

    Grafana Data Source

    The Prometheus data source inside Grafana uses:

    http://localhost:9090

    This works because Grafana and Prometheus are both running on the Raspberry Pi 5.

    Dashboard Used

    Dashboard ID Purpose
    Node Exporter Full 1860 Displays CPU, memory, disk, network, uptime, and node metrics

    How to Use Grafana

    1. Open Grafana on RP5.
    2. Go to Dashboards.
    3. Open Node Exporter Full.
    4. Select Job: node.
    5. Select the required Raspberry Pi from the Nodename dropdown.
    6. Set time range to Last 15 minutes.
    7. Set refresh interval to 10s.

    Dashboard Status

    • Grafana is installed and running on RP5.
    • Prometheus is connected as the data source.
    • The Node Exporter Full dashboard is imported.
    • Live metrics are visible for the monitored Raspberry Pi nodes.
    • Some panels may show N/A if that exact metric is not exposed by Raspberry Pi OS.
